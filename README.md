# تطبيق "أبوي وأمي" (My Parents Call) 🏡❤️
### تطبيق اتصال صوتي ومرئي مخصص، عالي الأمان ومناسب لكبار السن (WebRTC / VoIP)

تطبيق اتصال مباشر بكبسة زر واحدة مصمم خصيصاً للتواصل العائلي مع الوالدين بأعلى درجات السهولة والخصوصية، مع تحصين سيبراني شامل ضد التنصت واعتراض البيانات (Man-in-the-Middle) بعد الرفع والاستضافة.

---

## 🌟 أبرز المميزات

1. **واجهة مخصصة ومبسطة جداً لكبار السن**:
   - أزرار ضخمة عالية التباين (WCAG AAA) تناسب ضعف النظر وضعف دقة اللمس.
   - كبسة زر واحدة: **"اتصال بأبي"** و **"اتصال بأمي"** للأبناء، وزر عملاق **"اتصال بالأولاد"** للوالدين.
   - شاشة رنين بصوت واضح ومرئي ونمط اهتزاز لتنبيه الوالدين بسرعة وسهولة.
2. **اتصال مباشر عالي الدقة (WebRTC P2P)**:
   - مكالمات فيديو وصوت واضحة خالية من التقطيع مع معالجة الصدى والضوضاء.
   - دعم التبديل التلقائي بين الكاميرا الأمامية والخلفية في الهواتف.
   - دعم الترحيل المشفر عبر CoTURN في حال وجود شبكات وجدران حماية معقدة (Symmetric NAT).
3. **أمان وحماية سيبرانية من الدرجة العسكرية (Production Hardening)**:
   - **تشفير طرف إلى طرف (End-to-End Encryption)**: تدفقات الصوت والفيديو مشفرة إجبارياً عبر **DTLS-SRTP** بمفاتيح عشوائية لكل مكالمة لا يملكها حتى مزود الإنترنت.
   - **المصادقة والتحقق**: رمز PIN سري مشفر بـ bcrypt وتوليد رموز JWT قصيرة الأجل (15 دقيقة) مشفرة بـ HMAC-SHA256 لمصافحة WebSocket.
   - **بيانات اعتماد ترحيل مؤقتة (Ephemeral TURN Credentials)**: توليد حسابات مؤقتة بصلاحية 30 دقيقة تمنع استغلال خادم الترحيل أو سرقة الباندويث.
   - **حماية ضد DoS/DDoS**: Rate Limiting متعدد المستويات على الـ HTTP وعلى أحداث الـ WebSockets لمنع الفيضان والإغراق.
   - **تحصين الخادم**: ترويسات أمان صارمة عبر Helmet، سياسة CORS دقيقة، وتدقيق صارم لكافة الحزم عبر Zod لمنع حقن البيانات (Injection Prevention).

## 🚀 التشغيل والتجربة محلياً (Local Development)

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. بدء تشغيل الخادم:
```bash
npm start
```
أو وضع التطوير مع التحديث التلقائي:
```bash
npm run dev
```

### 3. تجربة الاتصال بين جهازين أو نافذتين:
1. افتح المتصفح على الرابط: `http://localhost:3000`
2. **النافذة الأولى**: اختر هوية **الابن / الابنة**، أدخل الرمز السري: **`2026`**، ثم اضغط "تسجيل الدخول".
3. **النافذة الثانية (نافذة خاصة أو جهاز آخر على نفس الشبكة)**: اختر هوية **الوالد (أبي)** أو **الوالدة (أمي)**، أدخل الرمز: **`2026`**، ثم اضغط "تسجيل الدخول".
4. ستلاحظ ظهور مؤشر الأخضر `متاح الآن` في كلا النافذتين في الوقت الفعلي!
5. اضغط زر **"اتصال بأبي"** وسيرن المتصفح الآخر فوراً، وعند الضغط على الزر الأخضر الكبير **"رد على المكالمة"**، تبدأ المكالمة المرئية والصوتية المشفرة فوراً مع المؤقت وأدوات التحكم.

## 🔑 كيفية تغيير الرمز السري العائلي (Family PIN)

الرمز السري الافتراضي في ملف `.env` هو: `2026`.
إذا أردت تغييره إلى رمز آخر (مثلاً `7788`):
1. قم بتوليد الهاش الجديد عبر سطر الأوامر:
   ```bash
   node -e "console.log(require('bcryptjs').hashSync('7788', 10))"
   ```
2. استبدل القيمة الناتجة في ملف `.env`:
   ```env
   FAMILY_PIN_HASH=القيمة_الجديدة_الناتجة
   ```
